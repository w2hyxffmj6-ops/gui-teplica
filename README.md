# Greenhouse Microclimate Control System

Это простое GUI-приложение, разработанное на Python с использованием библиотеки `tkinter`. Оно моделирует систему управления микроклиматом в теплице: отображает текущие параметры среды (температура, влажность, освещённость), позволяет задавать целевые значения и управлять исполнительными устройствами (обогреватель, вентилятор, насос, освещение) в ручном или автоматическом режиме.

Приложение создано в учебных целях для демонстрации основ разработки графического интерфейса, событийно-ориентированного программирования и простейших алгоритмов автоматического регулирования.

## Функциональные возможности

- **Отображение текущих показаний**:
  - Температура воздуха (°C)
  - Относительная влажность (%)
  - Уровень освещённости (условные люксы)

- **Задание целевых параметров** с помощью ползунков:
  - Желаемая температура (от 10 до 35 °C)
  - Желаемая влажность (от 30 до 90 %)

- **Управление устройствами** (кнопки с цветовой индикацией):
  - Обогреватель
  - Вентилятор
  - Насос (имитация полива)
  - Освещение

- **Выбор режима работы**:
  - **Ручной** – пользователь самостоятельно включает/выключает устройства.
  - **Автомат** – система автоматически поддерживает заданные температуру и влажность, а также включает освещение при низком уровне освещённости.

- **Симуляция изменения параметров**:
  - Каждую секунду значения обновляются с учётом состояния устройств и случайных флуктуаций.
  - Имитируется влияние устройств: обогреватель повышает температуру, вентилятор охлаждает и снижает влажность, насос увлажняет, освещение повышает освещённость и немного греет.

## Технологии

- **Python 3.x**
- **tkinter** – стандартная библиотека для создания графического интерфейса (входит в состав Python)
- Дополнительные модули: `random`, `math` (используются для симуляции)

## Установка и запуск

### Требования

- Установленный Python версии 3.6 или выше (рекомендуется 3.10+)
- Библиотека `tkinter` (обычно устанавливается вместе с Python, но в некоторых дистрибутивах Linux может отсутствовать)

### Инструкция по запуску

1. **Клонируйте репозиторий** или скачайте файл `greenhouse.py`:
   ```bash
   git clone https://github.com/yourusername/greenhouse-control.git
   cd greenhouse-control
   ```

2. **Убедитесь, что Python установлен** и доступен из командной строки:
   ```bash
   python --version
   ```

3. **Запустите приложение**:
   ```bash
   python greenhouse.py
   ```

   Если используется Linux и возникает ошибка "No module named tkinter", установите пакет:
   ```bash
   sudo apt update
   sudo apt install python3-tk
   ```

4. **Использование**:
   - После запуска откроется окно с интерфейсом.
   - Ползунками выберите желаемые температуру и влажность.
   - Переключите режим (Ручной/Автомат).
   - В ручном режиме нажимайте кнопки устройств для включения/выключения (кнопка подсвечивается зелёным).
   - Наблюдайте за изменением параметров в реальном времени.

## Пояснение ключевых частей кода

### 1. Инициализация приложения (`__init__`)

```python
class GreenhouseApp(tk.Tk):
    def __init__(self):
        super().__init__()
        self.title("Управление микроклиматом в теплице")
        self.geometry("600x500")
        ...
        self.mode = tk.StringVar(value="manual")
        self.create_widgets()
        self.update_simulation()
```

- Создаётся главное окно, задаётся заголовок и размер.
- Инициализируются переменные состояния: текущие параметры среды, целевые значения, флаги устройств, режим работы.
- Вызывается метод `create_widgets()` для построения интерфейса.
- Запускается циклическое обновление симуляции через `update_simulation()`.

### 2. Создание интерфейса (`create_widgets`)

Интерфейс разбит на логические группы с помощью `ttk.LabelFrame`:

- **Текущие показания** – три метки с крупным шрифтом.
- **Целевые параметры** – два ползунка (`ttk.Scale`) и метки для отображения значений.
- **Управление устройствами** – четыре кнопки, каждая связана с соответствующей функцией включения/выключения.
- **Режим работы** – две радиокнопки, связанные с переменной `self.mode`.

Методы `on_target_temp_change` и `on_target_humidity_change` обновляют метки при перемещении ползунков.

### 3. Обработка нажатий кнопок

```python
def toggle_heater(self):
    if self.mode.get() == "manual":
        self.heater_on = not self.heater_on
        self.update_button_color(self.btn_heater, self.heater_on)
```

- Каждая кнопка в ручном режиме переключает соответствующий флаг и меняет цвет через `update_button_color`.
- В автоматическом режиме кнопки блокируются (логически, но визуально остаются активными – это можно доработать).

### 4. Автоматическое регулирование (`auto_control`)

```python
def auto_control(self):
    if self.mode.get() == "auto":
        # Температура
        if self.temperature < self.target_temp - 0.5:
            if not self.heater_on:
                self.heater_on = True
                self.update_button_color(self.btn_heater, True)
        elif self.temperature > self.target_temp + 0.5:
            if not self.fan_on:
                self.fan_on = True
                self.update_button_color(self.btn_fan, True)
        else:
            # Выключить обогреватель и вентилятор, если температура в норме
            ...
        # Влажность и освещение регулируются аналогично
```

- Простейший двухпозиционный регулятор с гистерезисом (±0.5°C для температуры, ±2% для влажности).
- Включает обогреватель при недостаточной температуре, вентилятор – при избыточной.
- Насос включается, если влажность ниже целевой, и выключается при превышении.
- Освещение включается, если освещённость падает ниже 300 (имитация ночи).

### 5. Симуляция физических процессов (`simulate_environment`)

```python
def simulate_environment(self):
    if self.heater_on:
        self.temperature += 0.2
    if self.fan_on:
        self.temperature -= 0.15
        self.humidity -= 0.1
    ...
    self.temperature += random.uniform(-0.1, 0.1)
    self.humidity += random.uniform(-0.2, 0.2)
    ...
    # Ограничения
    self.temperature = max(5, min(45, self.temperature))
```

- Моделирует влияние каждого устройства на параметры с фиксированными коэффициентами.
- Добавляет случайные возмущения для реалистичности.
- Ограничивает значения в разумных пределах.

### 6. Цикл обновления (`update_simulation`)

```python
def update_simulation(self):
    self.auto_control()
    self.simulate_environment()
    self.update_display()
    self.after(1000, self.update_simulation)
```

- Вызывается каждую секунду (1000 мс).
- Последовательно выполняет автоматическое управление, обновление среды и обновление меток на экране.
- Рекурсивно планирует следующий вызов через `after`.
